# Send Network Iowa

**Department:** mission  
**Live:** https://sendnetworkiowa.vercel.app  
**Repo:** https://github.com/mheerema/send-network-iowa

---

## Stack

Next.js 16 App Router, TypeScript (strict), Tailwind CSS v4, ESLint  
Local dev: `npm run dev`

---

## Site Purpose

Funnel to sendnetwork.com. SNI provides Iowa-specific context and trust.  
- Planters → https://www.sendnetwork.com/plant/  
- Churches → https://www.sendnetwork.com/send/

---

## Asset Source

Official brand assets come from the **NAMB Enterprise Canva account** (Matt has access).  
Export to `public/images/brand/` — SVG for logos, PNG/WebP for graphics.
